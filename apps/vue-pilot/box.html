Box

Wrap content in an HTML container with optional padding from the spacing scale.

Example

Usage

import { Box } from '@my-design-system/vue'
import '@my-design-system/vue/styles.css'
<Box as="section" padding="medium" aria-label="Overview">
  Project overview
</Box>
  • as selects the HTML element and defaults to div. Give landmarks an accessible name when appropriate.
  • padding applies to all sides. It defaults to none and also accepts small, medium, large, and xLarge.
