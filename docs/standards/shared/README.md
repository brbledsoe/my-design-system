# Shared standards

Use the approved standard for the decision at hand. The [Vue task index](../vue/README.md) links directly to the corresponding Vue conventions.

| Decision | Standard |
| --- | --- |
| Decide what a consumer should configure | [Component API design](component-api-design.md) |
| Choose the owner of a helper, type or behavior | [Code colocation](code-colocation.md) |
| Expose a module or type to consumers | [Public API boundaries](public-api-boundaries.md) |
| Name a component-owned file | [Naming conventions](naming-conventions.md) |
