# Agent instructions

- Edit reusable code in `packages/` and consuming examples in `apps/`. Treat the ERIQ snapshot in `references/` as read-only reference material.
- Before editing the Vue library, read [Vue architecture](docs/architecture/vue.md).
- For implementation standards or documentation changes, use the [documentation map](docs/README.md) to find the guidance relevant to the task.
- Before adding or changing a component, read [Add a catalog entry](README.md#add-a-catalog-entry). Follow the closest maintained example for naming, placement, and formatting.
- After editing, use the [checks for the change](README.md#verify-a-change).
